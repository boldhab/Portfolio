# Accessibility audit

The audit checks page headings and landmarks, the skip link, mobile disclosure, accessible control names, focus indicators, field labels and feedback, alt text, color tokens, and reduced motion. Project and experience filters use grouped toggle buttons, and the screenshot viewer uses a native modal that makes the surrounding document inert. The project results section has a stable accessible name, and the filtered count is a status message. Loading skeletons and screenshot zoom effects respect reduced motion.

See [test results](../testing/test-results.md) for keyboard and browser coverage. A WCAG 2.2 AA conformance claim requires assistive-technology and manual review. In particular, a real screen-reader pass and a production gallery pass with published screenshots remain open.
